# Linguistic AI & Data Engineering Suite

Welcome to my professional portfolio of Python tools designed for the AI and Localization industry. This repository contains end-to-end solutions for handling, cleaning, and auditing bilingual datasets for Machine Learning.

## 📂 Projects Included

### 1. [Linguistic Data Cleaner](./Project-01-Data-Cleaner/)
Automated pipeline for cleaning medical datasets. Uses **Pandas** and **RegEx** to remove HTML noise, duplicates, and structural errors, ensuring 100% data readiness for LLM training.

### 2. [Automated NMT Quality Scorer](./Project-02-NMT-Scorer/)
A diagnostic tool that evaluates Machine Translation using **SacreBLEU**. It features a unique **Hybrid Validation Layer** to detect critical semantic errors that automated metrics often miss.

---
**Tech Stack:** Python, Pandas, SacreBLEU, RegEx, Openpyxl.
